# M4.5 plan: menus, GIFs and quick voice controls

Status: draft for Jaakko's sign-off. Implements the M4.5 section of [milestones.md](milestones.md). Results go in `docs/m4.5-results.md`.

Working agreement, as in M4:
- Each finished task is committed and pushed, with `pnpm verify` run right before the commit.
- Agents work on the local dev stack at `http://localhost`. On production they only deploy `/app` and run `routes.ts` afterwards.
- Every task ends deployed to production's `/app` for Jaakko's review.

## Tasks

### 1. Probes

On the local stack, in the scratchpad. They answer:
- **Mark unread**: does Stoat accept an acknowledgement that moves backwards?
- **Mark a server read**: does `PUT /servers/{id}/ack` clear every channel, and what events reach the other devices?
- **GIPHY**:
  - Can Caddy forward `/giphy/` to GIPHY's API with the key added on the server?
  - What does the beta key allow per hour?
  - Does January give a pasted `giphy.com` link a GIF embed?
- **Send-side bandwidth estimation** (`use_send_side_bwe` in `livekit-local.yml`): with `share.ts`, does a viewer get 1080p back after the downlink squeeze?

**Done when** each has an answer in m4.5-results.md.

### 2. Message, link and image menus

**Built**:
- **Right-click on a message**:
  - quick reactions from frequently used emoji, and "Add reaction",
  - Edit, Reply, Pin, Copy text, Copy link, Copy ID and Delete, each only when allowed,
  - Mark unread, if task 1 allows it.
- **Links**: Open link, Copy link.
- **Images and GIFs**: Copy image, Save image, Open original.
- **Keyboard**: the context-menu key and Shift+F10 open the same menus.

**Done when** a live check opens each menu by mouse and by key, and every item does what it says.

### 3. Server menu and unread count in the tab

**Built**:
- "Mark as read" in the server icon's menu.
- The tab's title shows unread mentions and DMs, as `(3) Concord`.

**Done when** marking a server read clears it on a second device of the same account, and the title follows the count.

### 4. Quick voice controls

**Built**:
- **Dock menus** from chevrons beside the microphone and headphones: device, volume and a link to Voice and video settings.
- **Voice panel**: a noise suppression toggle.
- **Shortcuts**: Ctrl+Shift+M mutes and Ctrl+Shift+D deafens, while the tab has focus.
- **Rename**: noise suppression "Off" becomes "Browser default", which is what it does.

**Done when** each control changes the live call, shown in `voice.ts` by bytes sent and the mute icon.

### 5. Per-user volume everywhere

**Built**:
- The participant menu in the member list and the DM header too.
- A small volume mark on a participant set away from 100 %.
- A volume slider for a stream's audio on its tile.

**Done when** a volume set from the member list holds in the call and after a reload.

### 6. Click to watch a stream

**Built**:
- A screen share shows as a "Watch stream" tile, and its video subscribes only once clicked.
- "Stop watching" in the tile's menu.

**Done when** `share.ts` shows no video arriving for a viewer before the click, and 1080p after it.

### 7. GIF picker

**Built**:
- A GIF tab in the emoji picker, with trending and search.
- "Powered by GIPHY", as GIPHY's terms require.
- Searches go through Caddy's `/giphy/` route, so the key stays on the server.
- Results load through January's proxy, so GIPHY never sees members' addresses.
- Picking a GIF sends its link, which renders as the GIF embed.

**Done when**:
- a GIF picked by one persona plays for another,
- no request from the client leaves our origin, checked from the page's network log.

### 8. Voice channel settings and voice fixes

**Built**:
- The user limit in a voice channel's settings.
- Join, leave and ring sounds through the chosen speaker and output volume.
- Gaining Speak mid-call publishes the microphone without a rejoin.
- `use_send_side_bwe`, if task 1 showed it helps and Jaakko agrees.

**Done when** a limit of 2 makes a third persona get "This voice channel is full".

### 9. Upstream

**Built**: a pull request text for Stoat's January, adding the Instagram embed fixers (kkinstagram, ddinstagram, instagramez) to the sites it fetches as Discord. Jaakko files it, or asks an agent to.

**Done when** the text and a tested regex are in m4.5-results.md.

## Decisions

Each is a recommendation that sign-off accepts unless you say otherwise.

1. **GIPHY through Caddy, no new service.**
   - The beta key's hourly limit is shared by everyone. Task 1 measures it.
   - If it's too low, GIPHY's production key needs an application with screenshots.
2. **Restart LiveKit only on a renewed TURN certificate.** It is in the repo since M4. Sign-off applies it to production with `pnpm deploy:stack:prod`.
3. **Streams start unwatched**, as on Discord. This saves the VPS's upload, which five viewers of a 1080p60 share would otherwise take at about 8 Mbps each.
4. **Out of M4.5**:
   - threads, forwarding, bookmarks, reminders, apps, soundboard, activities and stickers: Stoat doesn't have them,
   - push-to-talk with another window focused: M5,
   - server-wide search: decision gate criterion 2.
5. **Order**: M4.5 can start now. It is client-side and mostly survives a change of backend. The voice evening still decides decision gate part B.
